Environment Promotion

Promote immutable architecture releases into a separately controlled metadata environment. Environment Promotion is independent from Architecture Control: it deploys metadata; Architecture Control reviews and executes the resulting physical architecture.
Promotion flow
1 Release
Capture an immutable DEV metadata release.
2 Review
Compare the release with current TEST or PROD metadata.
3 Approve
Approve the exact plan and bind it into an immutable package.
4 Deploy
Check live drift, confirm the package ID and apply through the target runner.
5 Audit
Read immutable convergence evidence from the target runner.
Target metadata is mutated only during Deploy, after exact approval and a live drift check. Environment Promotion deploys metadata only. Physical architecture changes remain a separate Architecture Control workflow.
